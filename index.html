02. Projetos em Destaque

AI Engineering / LLM Infrastructure

🤖 LLM Inference Service

API resiliente e assíncrona de inferência para aplicações baseadas em LLMs, desenvolvida em Python e FastAPI com integração multi-provider entre Groq e Gemini. Implementa retries com exponential backoff e jitter, timeouts, controle de concorrência por provider, model fallback e provider fallback com proteção contra ciclos. Inclui rate limiting por cliente, classificação e normalização de erros dos provedores, validação tipada de configurações e requisições, rastreamento por request ID e métricas de tokens e latência. O projeto possui frontend público integrado e uma suíte com 44 testes automatizados.

Backend & IA

💰 CashFlow API

API financeira desenvolvida em Python e FastAPI para gerenciamento de receitas, despesas, categorias e relatórios financeiros. Inclui assistente de IA integrado à OpenAI, capaz de analisar os dados reais do usuário e responder perguntas financeiras em linguagem natural. O projeto utiliza arquitetura em camadas, autenticação JWT, SQLAlchemy, validação com Pydantic, Docker e uma suíte com 67 testes automatizados em Pytest.

Data Analytics / Python

📊 Sales Insights Pipeline

Pipeline automatizado de análise de vendas desenvolvido em Python. Processa arquivos CSV, realiza validação e limpeza de dados, calcula métricas financeiras, identifica outliers e gera insights e relatórios HTML automaticamente. A arquitetura modular baseada em POO separa carregamento, processamento, análise, visualização e geração de relatórios. O pipeline processa 100 mil registros em aproximadamente 8,5 segundos.
